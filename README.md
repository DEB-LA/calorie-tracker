# 🔥 NutriTrack - Vanilla Calorie & Macro Tracker

A lightweight, responsive calorie and macronutrient tracker built with **100% vanilla HTML, CSS, and JavaScript**. No external frameworks, no Tailwind, no CSS variables, and no backend required—all data is persisted locally in the web browser.

## 🚀 Features

- **Energy & Macro Budget**: Set daily calorie and macro (protein, carbs, fat) targets.
- **Real-Time Visual Indicators**: Color-coded progress bars and budget counters that warn you when you're over your daily limit.
- **Meal Breakdown**: Categorize items into Breakfast, Lunch, Dinner, and Snacks with individual subtotal calculations.
- **Quick-Add Presets**: Fast-log common food items (boiled eggs, bananas, chicken breast, oatmeal, etc.) with one click.
- **Interactive Water Tracker**: Visual 8-glass water tracker (in increments of 250 ml).
- **Date Navigation**: Switch between days or pick a specific date to view historical logs.
- **Live Search & Filter**: Filter through today's meals instantly.
- **Data Persistence**: Automatic saving to browser `localStorage`.
- **Backup & Restore**: Export your data to a JSON file or import existing backups anytime.

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure
- **CSS3**: Pure vanilla CSS (no variables, no Tailwind, fully responsive)
- **JavaScript (ES6+)**: Vanilla DOM manipulation and `localStorage` state management

## 💻 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/DEB-LA/calorie-tracker.git

# Navigate to the folder
cd calorie-tracker

# Open in your browser (macOS)
open index.html
```

Or double-click `index.html` in your file explorer.
